# NLP Çalışmaları

Turkcell kurslarında yazdığım doğal dil işleme (NLP) kodları ve uygulamaları.

| Klasör | Konu |
|--------|------|
| `metin_on_isleme` | Metin ön işleme (temizleme, tokenization vb.) |
| `metin_temsili/BoW` | Bag of Words (IMDB veri seti) |
| `metin_temsili/N-Gram` | N-Gram |
| `metin_temsili/TF-IDF` | TF-IDF (spam veri seti) |
| `metin_temsili/Word-Embedding` | Word Embedding (IMDB veri seti) |
| `transformers` | Transformers |

Ortam: `environment.yml`

## Kullanım

```bash
conda env create -f environment.yml
jupyter notebook
```
